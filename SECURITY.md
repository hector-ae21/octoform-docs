# Security policy

The documentation repository contains no runtime service, token, or governed
repository data. Security reports may still concern the publication pipeline,
unsafe guidance, a dependency, or content that could expose credentials.

Do not open a public issue for a suspected vulnerability or exposed secret.
Use GitHub's private vulnerability reporting for
[hector-ae21/octoform](https://github.com/hector-ae21/octoform/security/advisories/new).
Include the affected page or workflow, impact, reproduction steps, and a safe
way to contact you.

Remove exposed credentials from use immediately; rewriting documentation
history is not a substitute for revocation and rotation.
